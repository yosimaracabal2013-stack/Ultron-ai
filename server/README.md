# ULTRON inference server

This server loads the independently trained ULTRON v0.2 checkpoint and exposes two endpoints:

- GET /health
- POST /chat with {"message":"Hello"}

The server needs these two trained files:

- ai/checkpoints/ultron_v0_2.pt
- ai/checkpoints/tokenizer_v0_2.json

They are generated by the v0.2 Colab notebook. Do not commit private credentials or API keys.

Run locally from the repository root:

    pip install -r server/requirements.txt
    uvicorn server.main:app --host 0.0.0.0 --port 8000

Then test:

    curl http://localhost:8000/health

The GitHub Pages website is static, so it calls this server rather than trying to run PyTorch inside the page.
